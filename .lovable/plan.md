# Recap Output ကို ဘာတွေ ပြင်သင့်လဲ (ရိုးရိုးရှင်းရှင်း)

## အဓိကအဖြေ
ငါတို့ output က "အရည်အသွေး" မဆိုးဘူး။ ကွာနေတာက **ဇာတ်ကြောင်းပြောပုံ (script style)** ရယ်၊ **hook ရွေးပုံ** ရယ် ၂ ခုပဲ။ Video format, subtitle, resolution တွေ ပြင်စရာမလိုဘူး။

သူတို့ဟာက စာမပြောဘဲ **ဇာတ်လမ်းကို တိုက်ရိုက် ပြောပြသွားတာ** — "ပြီးတော့... အဲဒီအချိန်မှာ... သူမသိလိုက်တာက..." ဆိုပြီး လူတစ်ယောက် ဇာတ်လမ်းပြောပြနေသလို။ ငါတို့ဟာက "ဒီဇာတ်ကားမှာ ... ကို ဖော်ပြထားပါတယ်" ဆိုတဲ့ **အစီရင်ခံစာဆန်တဲ့ လေသံ** နည်းနည်း ပါနေတယ်။ အဲဒါက ကြည့်သူကို ဆက်ကြည့်ချင်စိတ် လျော့စေတယ်။

## ပြင်မယ့် ၂ ခု

### ၁။ Viral Hook ကို "အကောင်းဆုံးပြကွက်" ကနေပဲ ရွေးခိုင်းမယ်
အခုက စာသားအရ ရွေးနေတာမို့ သာမန်ပြကွက် ပါလာတတ်တယ်။ ပြောင်းမယ့်ပုံစံ —
- AI ကို ဇာတ်လမ်းတစ်ခုလုံးထဲက **ဇာတ်ရှိန်အမြင့်ဆုံး/အထူးဆန်းဆုံး အခိုက်အတန့် ၃ ခု** ရှာခိုင်းမယ် (ရန်ဖြစ်၊ လျှို့ဝှက်ချက်ပေါ်၊ သေဆုံး၊ ရုတ်တရက် ပြောင်းလဲမှု)
- အဲဒီ ၃ ခုထဲက အကောင်းဆုံးတစ်ခုကိုပဲ hook အဖြစ် ယူမယ်
- "အေးဆေးပြကွက်" (စကားပြောရုံ၊ လမ်းလျှောက်ရုံ) တွေကို hook အဖြစ် **လုံးဝ မယူရ** ဆိုပြီး တားမယ်
- သင့်တော်တဲ့ ပြကွက် မတွေ့ရင် hook မထည့်တော့ဘဲ ဇာတ်လမ်းအစကနေ တန်းစမယ် (မကောင်းတဲ့ hook ထက် hook မပါတာက ပိုကောင်းတယ်)

### ၂။ Script လေသံကို "ဇာတ်လမ်းပြောသူ" လေသံ ပြောင်းမယ်
- အစီရင်ခံဆန်တဲ့ စကားလုံးတွေ (ဒီဇာတ်ကားမှာ၊ ဖော်ပြထားတယ်၊ တင်ဆက်ထားတယ်) ကို ပိတ်မယ်
- ဇာတ်ကောင်နာမည်နဲ့ တိုက်ရိုက်ပြောမယ် — "မင်းယု က ..." ပုံစံ
- ဝါကျတိုတို၊ တစ်ဆက်တည်း စီးဆင်းအောင် (ပြီးတော့ / ဒါပေမယ့် / အဲဒီအချိန်မှာ)
- စိတ်ဝင်စားစရာ မေးခွန်းလေးတွေ ကြားထည့် — "ဘာလို့လဲ သိလား?"
- အဆုံးမှာ ဆက်ကြည့်ချင်စိတ်ဖြစ်အောင် ချိတ်ထားမယ် (အပိုင်း ၂ ရှိရင် ပိုသင့်)

## မထိတဲ့အပိုင်း
AV sync, hard-cut seek, zoom-in, subtitle style, resolution, credit/logic — ဘာမှ မထိပါဘူး။

## နည်းပညာအကျဉ်း
`supabase/functions/recap-script-generator/index.ts` ရဲ့ prompt အပိုင်း ၂ နေရာပဲ ပြင်မယ် — (က) hook ရွေးချယ်မှု စည်းမျဉ်း (ဇာတ်ရှိန်မြင့် ၃ ခု ရှာ → အကောင်းဆုံး ၁ ခု ယူ → မရှိရင် hook ကျော်)၊ (ခ) narration tone စည်းမျဉ်း (documentary phrasing ပိတ်၊ storyteller phrasing ဖွင့်)။ Code logic, JSON schema, timing တွက်ချက်မှု မပြောင်းပါ။
